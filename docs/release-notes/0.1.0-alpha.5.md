# QueryMole 0.1.0-alpha.5

**QueryMole** is a revival of the classic MySQL Query Browser: the original Windows user interface, unchanged,
rebuilt with Free Pascal and Lazarus for current MySQL (5.7 to 9) and MariaDB (10.11, 11.4), on Windows and Linux.
This is its first public release.

- **Picks up where you left off:** on the first start, the stored connections and options of an installed MySQL
  Query Browser are copied into QueryMole's own settings folder (`%APPDATA%\QueryMole\` on Windows,
  `~/.config/querymole/` on Linux, from `%APPDATA%\MySQL\` or `~/.mysqlgui/`). The old folder is only read, never
  changed, so the original keeps working next to it.
- **Updates itself** from this project's GitHub releases, when you ask it to (see "Updates" below).
- **Current servers:** connections with TLS, the authentication of MySQL 8 and later, and a table editor whose data
  types and storage engines follow the connected server.

**This is an alpha.** It is meant for people who want to try it and report problems. Use a test account or a test
server, keep your own backups, and expect faults (see below). QueryMole is not affiliated with Oracle; "MySQL" is a
trademark of Oracle.

## Downloads

- **Windows (64 bit), with updates:** [`QueryMole-win-Setup.exe`](https://github.com/aurora/querymole/releases/download/v0.1.0-alpha.5/QueryMole-win-Setup.exe).
  Installs for the current user (no administrator rights) into `%LOCALAPPDATA%\QueryMole`. The installer is not
  signed yet, so Windows SmartScreen may warn: "More info", then "Run anyway".
- **Windows (64 bit), portable:** [`QueryMole-0.1.0-alpha.5-win64.zip`](https://github.com/aurora/querymole/releases/download/v0.1.0-alpha.5/QueryMole-0.1.0-alpha.5-win64.zip).
  Unpack and run `querymole.exe`. No updates: download the next version and replace the folder.
- **Linux (x86_64), with updates:** [`QueryMole.AppImage`](https://github.com/aurora/querymole/releases/download/v0.1.0-alpha.5/QueryMole.AppImage).
  Make it executable (`chmod +x`) and run it from a folder you can write to (for example `~/Applications`), so that
  it can replace itself when it updates.
- **Linux (x86_64), without updater:** [`QueryMole-0.1.0-alpha.5-x86_64.AppImage`](https://github.com/aurora/querymole/releases/download/v0.1.0-alpha.5/QueryMole-0.1.0-alpha.5-x86_64.AppImage).
- Both AppImages bring GTK2 and the other libraries and need glibc 2.34 or newer (RHEL 9, Ubuntu 22.04, Debian 12,
  Fedora 35 and newer), libstdc++ and an X server (XWayland on Wayland). Without FUSE 2 installed, start them with
  `--appimage-extract-and-run`.
- macOS: not yet.
- [`SHA256SUMS`](https://github.com/aurora/querymole/releases/download/v0.1.0-alpha.5/SHA256SUMS): checksums of the
  four files above (`sha256sum -c --ignore-missing SHA256SUMS`).

The other files of the release (`*.nupkg`, `releases.*.json`, `assets.*.json`, `RELEASES*`,

## Updates

**Help > Check for Updates ...** looks for a newer release on this project's GitHub page and offers to download and
install it, then restarts the program. It works in the Windows installation and in `QueryMole.AppImage`; in the
portable zip and in the AppImage without updater the entry is disabled. Pre-releases (alpha, beta) look at
pre-releases too. Nothing is checked or downloaded unless you choose the menu entry. (The earlier tags 0.1.0-alpha.1
to alpha.4 were test builds.)

## Changes since 0.1.0-alpha.4

For testers who update from the previous build:

- **Windows:** connecting to servers with TLS failed with "MySQL Error Number 2006, Server has gone away" for some
  servers (seen with MySQL 8 instances of a cloud provider). The connection now uses TLS without checking the
  certificate in a single attempt, as on Linux (ADR-0042).
- **Windows:** some context menus (schema tree, table editor) showed Chinese characters instead of their text.
- Smaller fixes of the same cause: the width of edit fields in the result grid and the table editor, the hint shown
  while dragging tables onto the query area, the width of message dialogs, quoting of a dragged table name, and the
  detection of multi-line values for tooltips and the field editor.

## What works

Connecting (TLS "preferred" with fallback), stored connections, the schema tree, the SQL editor with
highlighting, running queries, the result grid with editing, several result tabs, EXPLAIN, scripts with
breakpoints, export to CSV, HTML, XML, Excel and PLIST, the help panel (the reference comes from the connected
server), the table editor, options, text search and the regular expression importer. An automated suite runs
against MySQL 5.7, 8.0, 8.4, 9 and MariaDB 10.11 and 11.4.

## Known problems

- **Linux:** the window became unresponsive once after loading about two million rows. Not reproduced. As in the
  original, every row of a result is kept in memory, so very large results need a lot of it; add a `LIMIT`.
- Real mouse and keyboard use, drag and drop, bookmarks and history, and the field viewer have not been worked
  through on every platform.
- **Linux on a scaled desktop:** the program is laid out in pixels for 96 dpi; use the desktop's scaling for X11
  applications (KDE: "Legacy applications: scaled by the system"). The Linux build uses GTK2.
- **Linux:** passwords can be stored as "Plaintext" or "Obscured" only (no keyring); no global hot keys.
- Parts of the window look different under GTK2 than on Windows.
- The updater is new: if an update fails, download the release by hand and tell us what happened (Velopack writes
  `%LOCALAPPDATA%\QueryMole\velopack.log` on Windows and `/tmp/velopack_QueryMole.log` on Linux).

More in the [README](https://github.com/aurora/querymole/blob/v0.1.0-alpha.5/README.md) and in
[docs/linux-port.md](https://github.com/aurora/querymole/blob/v0.1.0-alpha.5/docs/linux-port.md).

## What changed against the original

This release changes what users see in a few places on purpose: the name and artwork (QueryMole), the version
(0.1.0 alpha.5, "based on MySQL Query Browser 1.2.4 beta"), the About dialog (credits of the revival, the copyright
notice, the licence note and the source address), the settings folder, the removed menu entries of products that no
longer exist, the bug report entries pointing to this project, the update entry and, on Linux, a free stand-in for
the Tahoma font (Wine's, LGPL) that the forms are laid out for. The decisions are in `docs/adr/` (ADR-0017,
ADR-0026, ADR-0028, ADR-0030 to ADR-0033, ADR-0037, ADR-0038).

## Reporting problems

<https://github.com/aurora/querymole/issues>, with the version (Help > About), the operating system (and desktop),
the server and its version, what you did in the last seconds, and, if the program ended, the file
`querymole.error.txt` next to it; with `QBR_TRACE=1` the program also writes `querymole.trace.txt`.
