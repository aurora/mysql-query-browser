# MySQL Query Browser (revival) 0.1.0-alpha.1

First public alpha of the revival of the classic MySQL Query Browser: the original Windows user interface, rebuilt
with Free Pascal and Lazarus for current MySQL (5.7 to 9) and MariaDB (10.11, 11.4), on Windows and Linux.

**This is an alpha.** It is meant for people who want to try it and report problems. Use a test account or a test
server, keep your own backups, and expect faults (see below). The name "MySQL Query Browser" is a working title:
"MySQL" is a trademark of Oracle, and this project is not affiliated with it. It will be renamed.

## Downloads

- **Windows (64 bit):** `qbr-0.1.0-alpha.1-win64.zip`. Unpack and run `qbr.exe`.
- **Linux (x86_64):** `MySQL_Query_Browser-0.1.0-alpha.1-x86_64.AppImage`. Make it executable and run it.
- macOS: not yet.

There is no update mechanism in the alpha: download the next version and replace the old one. The source code of
this release is the tag `v0.1.0-alpha.1` of this repository (the program is released under the GPL, version 2 or
later; the licence texts are in the packages).

## What works

Connecting (TLS "preferred" with fallback), stored connections, the schema tree, the SQL editor with
highlighting, running queries, the result grid with editing, several result tabs, EXPLAIN, scripts with
breakpoints, export to CSV, HTML, XML, Excel and PLIST, the help panel (the reference comes from the connected
server), options, text search and the regular expression importer. An automated suite runs against MySQL 5.7,
8.0, 8.4, 9 and MariaDB 10.11 and 11.4.

## Known problems

- **Linux:** a crash after connecting was seen once, and the window froze once while scrolling the schema tree of a
  database with many tables. Neither has been reproduced; if you see one, please tell us how it happened.
- Real mouse and keyboard use, drag and drop, bookmarks and history, and the field viewer have not been worked
  through on every platform.
- **Linux on a scaled desktop:** the program is laid out in pixels for 96 dpi; use the desktop's scaling for X11
  applications (KDE: "Legacy applications: scaled by the system"). The Linux build uses GTK2.
- **Linux:** passwords can be stored as "Plaintext" or "Obscured" only (no keyring); no global hot keys.
- Parts of the window look different under GTK2 than on Windows.

More in the [README](../../README.md) and in [docs/linux-port.md](../linux-port.md).

## What changed against the original

This release changes what users see in a few places on purpose: the version (0.1.0 alpha.1, "based on 1.2.4
beta"), the About dialog (credits of the revival, the licence note and the source address), the removed menu entries
of products that no longer exist, the bug report entries pointing to this project, and the hidden update menu entry.
The decisions are in `docs/adr/` (ADR-0017, ADR-0026).

## Reporting problems

<https://github.com/aurora/mysql-query-browser/issues>, with the version (Help > About), the operating system (and
desktop), the server and its version, what you did in the last seconds, and, if the program ended, the file
`qbr.error.txt` next to it; with `QBR_TRACE=1` the program also writes `qbr.trace.txt`.
