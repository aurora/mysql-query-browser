# QueryMole 0.1.0-alpha.9

**QueryMole** is a revival of the classic MySQL Query Browser: the original Windows user interface, unchanged,
rebuilt with Free Pascal and Lazarus for current MySQL (5.7 to 9) and MariaDB (10.11, 11.4), on Windows and Linux.

A bug-fix release for 0.1.0-alpha.8:

- **Connecting to a server that does not answer took about two and a half minutes**, at start and for every new
  connection; it now gives up after the connect timeout (20 seconds).
- **Windows: PuTTY keys (`.ppk`) and Pageant work** (in alpha.8 they failed because the bundled OpenSSL is version 4).

alpha.8 brought the first features the original never had, each off unless you use it:

- **SSH tunnel:** connect to servers that are only reachable through an SSH server, with OpenSSH keys, PuTTY keys
  (`.ppk`), ssh-agent or Pageant, or a password; host keys are checked against your `known_hosts`, and
  `~/.ssh/config` (host aliases, jump hosts) applies.
- **Connection manager:** a "Test" button, and groups of stored connections.
- **Export:** JSON, JSON Lines and TSV, settings for CSV (separator, header, quoting, line ending, UTF-8 BOM), and the
  existing formats fixed and faster.

**This is an alpha.** It is meant for people who want to try it and report problems. Use a test account or a test
server, keep your own backups, and expect faults (see below). QueryMole is not affiliated with Oracle; "MySQL" is a
trademark of Oracle.

## Updates

**Help > Check for Updates ...** in 0.1.0-alpha.8 (or alpha.7, alpha.6, alpha.5) finds this release, downloads and
installs it, then restarts the program; your settings and stored connections stay as they are. It works in the
Windows installation and in `QueryMole.AppImage`; in the portable zip and in the AppImage without updater the entry
is disabled. Nothing is checked or downloaded unless you choose the menu entry.

## Changes since 0.1.0-alpha.8

- **Connect timeout:** a failed connection was tried a second time without the default schema, and that second
  attempt ran without a timeout (about two minutes on Linux until the system gave up), so a server that was down or
  unreachable kept the connect dialog or the start waiting for about two and a half minutes. The second attempt now
  only follows "unknown database" and "no access to the database", and it keeps the timeout. A wrong password is no
  longer tried twice either (some servers block hosts after repeated failed logins).
- **Windows, SSH tunnel:** `.ppk` keys and Pageant looked for OpenSSL 3, but the package brings OpenSSL 4; they
  failed with "libcrypto not found". Both versions are looked for now. The rest of the SSH tunnel was not affected.

## Changes in 0.1.0-alpha.8

- **SSH tunnel** (ADR-0048). Under "Details >>" in the connect dialog and on "Connection Parameters" in Options >
  Connections, "Use SSH tunnel" with a "..." button opens the SSH settings: SSH host and port, user, and the login
  by agent (ssh-agent; on Windows the OpenSSH agent or PuTTY's Pageant 0.75 or later), a key file (OpenSSH, PEM or
  PuTTY `.ppk` of format 2 or 3, encrypted or not) or a password. Server Host and Port of the connection are then
  reached from the SSH server. An unknown host key is shown with its fingerprint and added to `known_hosts` only if
  you accept it; a changed key is refused. Settings from `~/.ssh/config` apply (host aliases, users, keys, jump
  hosts). All connections of a session share one tunnel, which is opened again after it broke. The settings are
  stored with the connection in a way earlier releases keep (they connect directly, though).
- **Connection manager** (ADR-0051): "Test" connects with the values shown (through the SSH tunnel too) and reports
  the server version or the error. Stored connections can be organised in groups: right-click the tree for "New
  Group...", "Rename Group..." and "Delete Group", and drag connections into a group. Earlier releases keep the
  groups and show the connections ungrouped.
- **Export** (ADR-0049, ADR-0050): new formats JSON, JSON Lines and TSV; CSV settings on the Browser options page
  (separator: comma, semicolon, tab or another character; header line; quoting; line ending; UTF-8 BOM for Excel).
  The defaults write CSV as before.
- **Export fixes:** an Excel export with an empty text value ended the program; HTML and PLIST wrote "(null)" for
  empty values; XML with NULL values or special characters in column names was not well-formed; DECIMAL columns were
  exported as text; binary values could produce invalid XML/Excel/PLIST files; exporting while a result was still
  loading could crash. The exporters are also two to eight times faster (`docs/export-review.md`).
- **Crash fix:** loading a schema whose stored procedures or functions the connected user may run but not see ended
  the program (`munmap_chunk(): invalid pointer`).
- **File dialogs (Linux):** the file types no longer show their patterns twice ("(*.csv) (*.csv)").
- **Busy indicator:** the animated QueryMole plays top right while a query runs, where the original showed its
  dolphin.

## What works

Connecting (TLS "preferred" with fallback), stored connections, the schema tree, the SQL editor with
highlighting, running queries, the result grid with editing, several result tabs, EXPLAIN, scripts with
breakpoints, export to CSV, HTML, XML, Excel and PLIST, the help panel (the reference comes from the connected
server), the table editor, options, text search and the regular expression importer. An automated suite runs
against MySQL 5.7, 8.0, 8.4, 9 and MariaDB 10.11 and 11.4.

## Known problems

- **Linux on Wayland:** started from a terminal, the program prints messages from the Qt toolkit about combo boxes
  and mouse grabbing; they are harmless. If dragging (splitters, column widths, drag and drop) misbehaves, start it
  with `QT_QPA_PLATFORM=xcb` (it then runs through XWayland) and tell us.
- As in the original, every row of a result is kept in memory: two million short rows take about half a gigabyte, so
  for very large results add a `LIMIT`.
- Real mouse and keyboard use, drag and drop, bookmarks and history, and the field viewer have not been worked
  through on every platform.
- **New in alpha.8 and not yet tried on every platform:** the SSH tunnel on Windows (Pageant, the OpenSSH
  agent), and the connection manager's context menu and drag and drop into groups.
- **SSH tunnel:** the SSH password and key passphrases are asked for when connecting and kept only while the program
  runs; they are not stored. An earlier release opening a connection with SSH settings connects directly to the
  server host (often `127.0.0.1`) and may reach a different server.
- Groups of connections are not shown in the connect dialog's "Stored Connection" list yet, and an empty group is
  not kept.
- An export while a result is still loading writes only the rows loaded so far.
- **Linux on a scaled desktop:** the program is laid out in pixels for 96 dpi; Qt scales the whole window with the
  desktop's scale factor.
- **Linux:** passwords can be stored as "Plaintext" or "Obscured" only (no keyring); no global hot keys.
- Parts of the window look different under Qt on Linux than on Windows (for example the captions of group boxes sit
  above their frame).
- If an update fails, download the release by hand and tell us what happened (Velopack writes
  `%LOCALAPPDATA%\QueryMole\velopack.log` on Windows and `/tmp/velopack_QueryMole.log` on Linux).

More in the [README](https://github.com/aurora/querymole/blob/v0.1.0-alpha.9/README.md) and in
[docs/linux-port.md](https://github.com/aurora/querymole/blob/v0.1.0-alpha.9/docs/linux-port.md).

## What changed against the original

This release changes what users see in a few places on purpose: the name and artwork (QueryMole), the version
(0.1.0 alpha.9, "based on MySQL Query Browser 1.2.4 beta"), the About dialog (credits of the revival, the copyright
notice, the licence note and the source address), the settings folder, the removed menu entries of products that no
longer exist, the bug report entries pointing to this project, the update entry and, on Linux, a free stand-in for
the Tahoma font (Wine's, LGPL, shipped without its embedded bitmaps) that the forms are laid out for, and Qt's Fusion
style with slightly more space in the menu bar and combo box lists. The decisions are in `docs/adr/` (ADR-0017,
ADR-0026, ADR-0028, ADR-0030 to ADR-0033, ADR-0037, ADR-0038, ADR-0044, ADR-0045).

Since parity with the original was reached (ADR-0047), new features are added on top: each is off unless used, keeps
the original's style, and keeps stored files readable by the release before. In this release: the SSH tunnel
(ADR-0048), JSON, JSON Lines and TSV export and the CSV settings (ADR-0049, ADR-0050), and the connection manager's
test button and groups (ADR-0051).

## Reporting problems

<https://github.com/aurora/querymole/issues>, with the version (Help > About), the operating system (and desktop,
with Wayland or X11), the server and its version, what you did in the last seconds, and, if the program ended, the
