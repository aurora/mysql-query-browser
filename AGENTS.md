# AGENTS.md

Guidance for AI coding agents (and humans) working in this repository. Keep it
accurate: when a command or rule here stops being true, fix this file.

## What this project is

A revival of the classic **MySQL Query Browser** as a cross-platform Free
Pascal / Lazarus application against current MySQL (5.7–9) and MariaDB, with
the **original Windows UI reproduced unchanged**. Read `README.md`,
`ROADMAP.md` and `docs/adr/` first; the ADRs are binding.

The one rule that shapes everything: **no UX changes** until functional parity
(ADR-0001). Do not "improve" layouts, icons, texts or behaviour while porting.
Anything that changes what a user sees needs an ADR first.

## Layout

| Path | What it is | Edit by hand? |
|---|---|---|
| `legacy/` | Original sources (Delphi 2006, gtkmm, Cocoa, C). Reference only. | **Never** |
| `backend/` | CMake build of the C libraries; `backend/src` is a copy of the needed `legacy` sources, `backend/compat` are shim headers | yes (C code, with care) |
| `bindings/myx_*_public_interface.pas` | Pascal interface layer | **No, generated** by `tools/gen_bindings.py` + `gen_classes.py` |
| `bindings/myx_types.pas`, `AuxLists.pas` | hand-written helpers for the generated units | yes |
| `app/` | Lazarus project (`qbr.lpi`), `src/` ported units, `compat/` replacement units, `forms/` `.lfm` files, `res/` compiled resources | see below |
| `app/forms/*.lfm`, `app/compat/Tnt*.pas` (aliases) | converted forms / generated aliases | **No, generated** (`tools/convert_forms.py`, `tools/gen_tnt_shims.py`) |
| `app/res/` | compiled `.res` files (git-ignored) | no, `tools/build_resources.py` |
| `tools/` | generators, converter, `lfmview` (form viewer), analysis scripts | yes |
| `tests/` | FPCUnit tests that run against real servers | yes |
| `docs/adr/`, `ROADMAP.md` | decisions and plan | yes, see "Decisions" |
| `docs/reconstructed/` | screenshots of the converted forms | regenerated by `tools/convert_forms.py` |

If you need a different generated result, change the generator, not its output.

## Toolchain (Windows, as set up on the development machine)

- Lazarus 4.8 / FPC 3.2.2 in `C:\lazarus` (`lazbuild.exe`, `fpc\3.2.2\bin\x86_64-win64\fpc.exe`).
- MSYS2 in `C:\msys64` with the mingw64 toolchain (gcc, cmake, ninja, glib2,
  libxml2, pcre, libmariadbclient). The DLLs it provides must be on `PATH` when
  running anything that loads `libmysqlx.dll`.
- Podman (with a `docker.bat` shim) for the test servers.
- Python 3 for the tools.

## Everyday commands

```bash
# backend (needs C:\msys64\mingw64\bin on PATH)
cmake -S backend -B backend/build -G Ninja && cmake --build backend/build

# regenerate the Pascal interface / shims, then verify struct layout against C
python tools/gen_bindings.py
python tools/gen_tnt_shims.py
python tools/check_bindings.py

# tests: build, then run against a server (QBR_TEST_PORT etc., see tests/README.md)
fpc -Fubindings -Fuapp/compat -FUtests/lib -FEtests/bin \
  -Fu/c/lazarus/fpc/3.2.2/units/x86_64-win64/fcl-fpcunit tests/qbr_tests.lpr
QBR_TEST_PORT=33306 tests/bin/qbr_tests.exe --all --format=plain   # backend/build and mingw64/bin on PATH
pwsh tests/run-matrix.ps1                # all supported servers in throw-away containers

# forms: convert everything and render screenshots into docs/reconstructed/
python tools/convert_forms.py            # needs tools/lfmview built: lazbuild tools/lfmview/lfmview.lpi
python tools/build_resources.py          # compile the .rc files into app/res/
lazbuild app/qbr.lpi                     # the application
```

A change is not done until the relevant tests pass **on the server matrix**,
not just on one server (version differences are where the bugs were).

## Conventions

- **Encoding:** UTF-8, LF line endings. The `legacy/` sources are Windows-1252
  with CRLF: convert when porting (`iconv -f cp1252 -t utf-8`).
- **Pascal modes:** ported units use `{$mode delphi}` to keep Delphi semantics;
  new tool/test code may use `objfpc`.
- **Porting a unit:** keep names, structure, comments and the original licence
  header; change only what the LCL/FPC requires. Replace third-party units by
  the shims in `app/compat/` (ADR-0007), do not port TNT/PNGImage code.
- **Strings** in the Pascal layer are UTF-8 `String`; `WideString` appears only
  where ported code still uses it.
- **Licence:** GPL-2.0-or-later (ADR-0011). New files start with
  `SPDX-License-Identifier: GPL-2.0-or-later` in the file's comment syntax;
  ported files keep their original header; generators emit the line themselves.
- **Never hand-edit `legacy/`.** Copy what you need and port the copy.
- **Test credentials** (`QBR_TEST_*`, containers `qbr-*`) are for throw-away local
  servers only. Never put real credentials or hosts in the repo.

## Decisions

An architecture-level decision gets an ADR in `docs/adr/` (template and
numbering in its `README.md`; ADRs are immutable, supersede instead of
editing). Ideas and open work go into `ROADMAP.md`. If you are about to make a
choice that a future contributor would ask "why?" about, write the ADR.

## Known pitfalls (each cost time once)

- **GUI-subsystem programs have no stdout.** `WriteLn` in `qbr.exe` (or any
  Lazarus GUI program) opens an error dialog and hangs. Report through a file,
  or build the tool as a console program (`tools/lfmview` is one).
- **Always run GUI/test programs with a timeout** (`timeout 60 ...`): a modal
  dialog blocks forever.
- **`windres` and backslashes:** its C preprocessor reads `\b`, `\i` in `.rc`
  paths as escapes; `tools/build_resources.py` normalises them.
- **MariaDB Connector/C >= 3.4 requires TLS by default** (ADR-0005). If a
  server without TLS suddenly fails to connect, look there first.
- **MariaDB reports its version as `5.5.5-10.x`**; version checks that read it
  as 5.5 are wrong (ADR-0004, not fixed yet).
- **Old C code and modern compilers:** expect undefined behaviour of the kind
  `&vec.front()` on empty vectors, implicit `int`, `NULL` in integer fields; see
  ADR-0003 for the ones already fixed.
- **Unsigned counters:** `for I := 0 to num - 1` with `num: cuint = 0` loops
  4 billion times; cast to `Integer` first.
- **Window screenshots on Windows 10/11** include an invisible border that
  `PrintWindow` leaves black; `tools/lfmview` trims it.
- **FPC does not allow a parameter with the same name as a field** (generated
  constructors use `ARecord`).
